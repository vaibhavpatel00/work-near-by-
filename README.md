# WorkNearBy - Hyperlocal Workspace Finder

WorkNearBy is a web application that helps users find workspaces nearby. It utilizes React, Vite, and Supabase.

Technologies Used:
React
Vite
Supabase
Vercel

Setup and Running Locally:
1 Clone the repository.
2 Run npm install to install dependencies.
3 Copy .env.example to .env and set VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY.
4 Run npm run dev to start the local development server.

Deploying to Vercel:
1 Connect this repository to your Vercel account.
2 Configure environment variables in the Vercel project settings.
3 Trigger a deployment by pushing to main branch.
